## 🚀 Installation

This package is designed for the GitHub profile repository:

`palla-mahesh/palla-mahesh`

Copy the complete contents of this package into the root of that repository.

## 📤 Push to GitHub

```bash
git add README.md .github/workflows/snake.yml SETUP.md
git commit -m "Create premium cybersecurity GitHub profile"
git push origin main
```

## 🐍 Enable the Contribution Snake

1. Open the repository on GitHub.
2. Select **Actions**.
3. Select **Generate GitHub Contribution Snake**.
4. Select **Run workflow**.
5. Wait for the workflow to finish.
6. Refresh your GitHub profile.

The workflow is scheduled to run daily as well.

## 🔐 GitHub Actions Permissions

The Snake workflow uses:

```yaml
permissions:
  contents: write
```

This allows the workflow to publish generated SVG files to the `output` branch.

## 📝 Important

The Snake image appears after the GitHub Action successfully creates the `output` branch and its SVG files.
